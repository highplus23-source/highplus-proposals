# 하이플러스컴퍼니 제안서

병의원 마케팅 제안서를 웹 링크로 발송하기 위한 정적 사이트입니다.

## 구조

병원 하나당 폴더 하나입니다.

```
jeonlumin/          전루민안과
  index.html
  assets/
```

## 새 제안서 추가하는 방법

1. 기존 폴더를 복사해 새 병원 이름의 폴더를 만듭니다.
2. `index.html` 안의 상호명, 진단 내용, 키워드를 교체합니다.
3. 커밋 후 push 하면 몇 분 안에 반영됩니다.

## 링크

`https://highplus23-source.github.io/highplus-proposals/폴더명/`

루트 주소에는 목록 페이지를 두지 않습니다. 링크를 직접 받은 사람만 열람하도록 하기 위해서입니다.
